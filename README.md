# GemCraft Panel

Окно-пульт для игры **GemCraft: Chasing Shadows**. Снимает окно игры 10 раз в секунду, распознаёт ману и игровые признаки и по галочкам ставит игру на паузу (пробелом) или выполняет цепочку действий клавишами и курсором.

## Что умеет

- **Снимок окна** — `capture.py`: поиск окна игры, захват кадра (PrintWindow).
- **Распознавание маны** — `mana_ocr.py`, `numread.py`, `numnet/`: OCR цифр маны по маскам и шаблонам.
- **Детекторы признаков** — `detectors.py`: индикаторы, плюсики, светлая волна, блоки волн, заморозка, водоворот, кнопка паузы.
- **Политика паузы** — `pause_policy.py`: решение, жать ли пробел.
- **Цепочка действий** — `chain.py`: шаги клавишами и курсором по точкам A–E.
- **Злость (enrage)** — `enrage.py`: режим «броски» по волнам.
- **Пульт** — `panel.py`: tkinter-окно поверх игры, галочки и поля.

## Запуск

Только Windows:

```
python panel.py
```

## Зависимости

- Python 3
- `pywin32`
- `opencv-python`
- `numpy`
- `torch` — только для обучения `numnet`

## Конфиг

Настройки пульта (область маны, галочки, точки цепочки A–E, режим злости) — в `digit_grab.json`.
